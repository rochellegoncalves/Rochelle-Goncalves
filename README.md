# Rochelle Gonçalves — Ritmo para a Gestão

Site institucional de página única para o Programa Ritmo para a Gestão, metodologia de gestão empresarial de Rochelle Gonçalves.

## Estrutura

- `index.html` — conteúdo e estrutura da página
- `assets/css/styles.css` — estilos (paleta de marca: verde profundo #0F2D24, verde oliva #3C4A38, dourado fosco #C8A869, champagne #E6DCC2, marfim #F7F5F0)
- `assets/js/script.js` — menu mobile e ano do rodapé

Site estático, sem dependências de build. Basta abrir `index.html` ou publicar via GitHub Pages.

## Publicar no GitHub Pages

1. No repositório, vá em **Settings → Pages**
2. Em **Source**, selecione a branch `main` (ou a branch atual) e a pasta `/ (root)`
3. Salve — o site ficará disponível em `https://<usuario>.github.io/<repositorio>/`
